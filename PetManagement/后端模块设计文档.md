# 后端模块设计文档

## 一、模块划分

### 1.1 模块列表

1. **管理员模块** (admin-module)
   - 管理员登录
   - 管理员信息管理
   - 管理员权限管理

2. **宠物管理模块** (pet-module)
   - 弃养宠物信息录入
   - 弃养宠物信息修改
   - 弃养宠物信息删除
   - 弃养宠物信息查询

3. **领养申请管理模块** (adoption-module)
   - 领养申请列表查看
   - 领养申请审核（通过/拒绝）
   - 审核意见填写

4. **预约管理模块** (appointment-module)
   - 预约信息查看
   - 预约确认
   - 预约取消

5. **用户端功能模块** (user-module)
   - 首页浏览模块
     - 待领养宠物列表展示
     - 宠物详情查看
     - 搜索功能
   - 领养申请模块
     - 在线提交领养申请
     - 申请状态查询
   - 预约管理模块
     - 在线预约探视
     - 预约信息查看
     - 预约取消
   - 个人中心模块
     - 个人信息管理
     - 我的领养申请记录
     - 我的预约记录

6. **文件上传模块** (upload-module)
   - 图片上传
   - 文件管理

### 1.3 依赖说明

- **管理员模块**: 作为基础模块，为所有其他模块提供管理员身份验证和权限控制服务
- **文件上传模块**: 为宠物管理模块提供图片上传功能
- **用户端模块**: 被领养申请模块、预约管理模块等依赖，提供用户基础信息和操作界面
- **宠物管理模块**: 被领养申请模块、预约管理模块等依赖，提供宠物基础信息
- **领养申请模块**: 依赖用户端模块、宠物管理模块，管理领养申请流程
- **预约管理模块**: 依赖用户端模块、宠物管理模块，管理宠物探视预约

## 三、其他模块概述

### 3.1 宠物模块

**功能概述**：
- 宠物信息管理：包括宠物基本信息（名称、品种、年龄、性别等）的增删改查
- 宠物分类管理：按品种、类型等进行分类管理
- 宠物健康记录：记录宠物的疫苗接种、体检、医疗等健康信息
- 宠物相册管理：管理宠物的照片和视频

**关键设计点**：
- 宠物与用户的关联关系：一个用户可以拥有多个宠物
- 健康记录的时间线设计：按时间顺序展示宠物的健康变化
- 相册的权限控制：宠物主人可以控制相册的访问权限

### 3.2 商品模块

**功能概述**：
- 商品信息管理：商品基本信息的增删改查
- 商品分类管理：多级分类体系
- 商品库存管理：库存的实时更新和预警
- 商品搜索：基于Elasticsearch的全文搜索

**关键设计点**：
- SKU设计：支持多规格商品
- 库存同步：与订单模块的库存同步机制
- 搜索优化：使用Elasticsearch提升搜索性能

### 3.3 购物车模块

**功能概述**：
- 购物车管理：添加、删除、修改商品数量
- 选中状态管理：支持部分商品结算
- 价格计算：实时计算购物车总价
- 库存校验：实时校验商品库存

**关键设计点**：
- 购物车持久化：支持登录和未登录用户
- 价格实时更新：商品价格变动时自动更新
- 跨端同步：支持多设备购物车同步

### 3.4 优惠券模块

**功能概述**：
- 优惠券发放：支持多种发放方式
- 优惠券使用：下单时使用优惠券
- 优惠券核销：订单完成后核销优惠券
- 优惠券统计：统计优惠券的使用情况

**关键设计点**：
- 优惠券类型：满减券、折扣券、免邮券等
- 使用规则：支持复杂的优惠规则
- 防刷机制：防止优惠券被恶意使用

### 3.5 消息通知模块

**功能概述**：
- 系统通知：发送系统级通知
- 订单通知：订单状态变更通知
- 推送管理：管理推送渠道和规则
- 通知历史：查看历史通知记录

**关键设计点**：
- 多渠道推送：支持APP推送、短信、邮件等
- 消息模板：支持自定义消息模板
- 推送策略：根据用户行为智能推送

### 3.6 统计分析模块

**功能概述**：
- 用户行为分析：分析用户行为数据
- 销售统计分析：统计销售数据
- 数据报表：生成各类数据报表
- 趋势预测：基于历史数据预测趋势

**关键设计点**：
