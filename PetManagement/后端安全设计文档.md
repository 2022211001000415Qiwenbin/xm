# 后端安全设计文档

## 一、安全设计目标

保障系统的数据安全和访问控制，确保用户数据的机密性、完整性和可用性。

## 二、认证与授权

### 2.1 认证方式

系统采用基于Token的认证方式，具体实现如下：

- **Token生成**：
  - 用户登录成功后，系统生成Token
  - 管理员Token格式：`admin-token-{adminName}`
  - 用户Token格式：`user-token-{username}`

- **Token传递**：
  - 使用HTTP请求头`Authorization`传递Token
  - Token格式：`Bearer {token}`

- **Token验证**：
  - 通过`AuthController.getUserInfo()`方法验证Token
  - 根据Token前缀判断用户类型（管理员/普通用户）
  - 从Token中提取用户名，查询数据库验证用户身份

### 2.2 权限控制模型

系统采用基于角色的访问控制（RBAC）模型：

- **角色定义**：
  - `admin`：管理员角色，拥有系统所有权限
  - `user`：普通用户角色，拥有基本操作权限

- **权限控制实现**：
  - 通过Token中的角色信息进行权限判断
  - 管理员可访问所有管理接口
  - 普通用户只能访问用户相关接口

### 2.3 实现方式

- **Token校验**：
  - 在需要认证的接口中，通过`@RequestHeader`获取Token
  - 解析Token获取用户信息和角色
  - 根据角色判断是否有权限访问

- **登录流程**：
  1. 用户提交用户名、密码和角色
  2. 系统使用MD5加密密码
  3. 根据角色查询对应的用户表（admin或user）
  4. 验证用户名和密码是否匹配
  5. 生成Token并返回给前端

## 三、数据安全

### 3.1 密码加密

- **加密算法**：使用MD5哈希算法
- **实现方式**：
  ```java
  String md5Password = DigestUtils.md5DigestAsHex(password.getBytes());
  ```
- **存储方式**：数据库中存储MD5加密后的密码

### 3.2 传输加密

- **HTTPS**：建议生产环境使用HTTPS协议传输数据
- **跨域配置**：
  - 允许所有域名跨域访问
  - 允许携带Cookie
  - 允许所有请求方法和请求头

### 3.3 敏感数据保护

- **身份证号**：存储在数据库中，建议在日志和响应中脱敏
- **手机号**：存储在数据库中，建议在日志和响应中脱敏
- **密码**：使用MD5加密存储，不记录明文密码

## 四、防攻击措施

### 4.1 SQL注入防护

- **ORM框架防护**：
  - 使用MyBatis-Plus作为ORM框架
  - 利用框架内置的SQL注入防护机制
  - 使用`QueryWrapper`进行查询，避免拼接SQL

- **预编译语句**：
  - MyBatis-Plus自动使用预编译语句
  - 参数化查询，防止SQL注入

### 4.2 XSS防护

- **输入验证**：
  - 对用户输入进行校验
  - 建议使用HTML转义处理用户输入

### 4.3 CSRF防护

- **Token认证**：使用Token进行身份认证，防止CSRF攻击
- **SameSite Cookie**：建议生产环境配置SameSite Cookie属性

### 4.4 接口防刷

- **建议措施**：
  - 实现接口限流机制
  - 添加验证码功能
  - 记录异常访问日志

## 五、安全配置

### 5.1 跨域配置

系统配置了CORS过滤器，允许跨域访问：

```java
@Configuration
public class CorsConfig {
    @Bean
    public CorsFilter corsFilter() {
        CorsConfiguration config = new CorsConfiguration();
        config.addAllowedOriginPattern("*");
        config.setAllowCredentials(true);
        config.addAllowedHeader("*");
        config.addAllowedMethod("*");

        UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
        source.registerCorsConfiguration("/**", config);
        return new CorsFilter(source);
    }
}
```

### 5.2 资源访问配置

配置静态资源访问路径：

```java
@Configuration
public class WebConfig implements WebMvcConfigurer {
    @Value("${upload.path:D:/upload}")
    private String uploadPath;

    @Override
    public void addResourceHandlers(ResourceHandlerRegistry registry) {
        registry.addResourceHandler("/images/**")
                .addResourceLocations("file:" + uploadPath + "/");
    }
}
```

## 六、安全建议

### 6.1 短期改进

1. **密码加密升级**：建议从MD5升级到BCrypt或PBKDF2
2. **Token安全**：建议使用JWT替代简单Token字符串
3. **输入验证**：添加更严格的输入验证规则
4. **日志脱敏**：在日志中对敏感信息进行脱敏处理

### 6.2 长期改进

1. **OAuth2集成**：支持第三方登录
2. **权限细化**：实现更细粒度的权限控制
3. **安全审计**：添加操作审计日志
4. **安全监控**：实现安全事件监控和告警
